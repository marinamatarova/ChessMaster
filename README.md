♟️ ChessMaster — шахматы (2D)
Классические шахматы в вашем терминале или окне. Играйте против друга на одном устройстве. Реализованы все основные правила: ходы фигур, взятие, рокировка, пешечное превращение, шах и мат.
Реализовано на 7 языках программирования для демонстрации алгоритмов и структур данных.

🧠 Концепция
ChessMaster — это полноценная шахматная программа, которая позволяет играть в шахматы в консоли или графическом интерфейсе. Реализованы:

✅ Все фигуры: король, ферзь, ладья, слон, конь, пешка.

✅ Правила ходов: стандартные движения, взятие, рокировка, взятие на проходе (en passant), превращение пешки.

✅ Проверка шаха и мата.

✅ Два режима: игра против другого игрока (на одном устройстве) или против ИИ (в планах).

✅ Цветной вывод в консоли (ANSI) или графический интерфейс.

🚀 Как запустить
Установите необходимые зависимости и запустите файл соответствующего языка.

Python
bash
python chess_python.py
C++
bash
g++ -std=c++17 chess_cpp.cpp -o chess
./chess
Java
bash
javac ChessJava.java && java ChessJava
C#
bash
dotnet run
Go
bash
go run chess_go.go
Rust
bash
cargo run
JavaScript (Node.js)
bash
node chess_js.js
